macOS

macOS 13 or later. The download has a .dmg and a .zip of ShareX.app.

Which one do I need?

Apple silicon (M1 and later) is arm64; Intel Macs are x64. Check under Apple menu > About This Mac > Chip or Processor.

Linux

X11 and Wayland (GNOME, KDE Plasma, Hyprland, sway). x64 or ARM64: run uname -m, x86_64 is x64 and aarch64 is ARM64.

How do I install it?

Each download is a .zip that GitHub adds around the file. Unzip it first.

.deb

sudo apt install ./ShareX-*-linux-x64.deb

.rpm

sudo dnf install ./ShareX-*-linux-x64.rpm
sudo zypper install --allow-unsigned-rpm ./ShareX-*-linux-x64.rpm   # openSUSE

AppImage

chmod +x ShareX-*-linux-x64.AppImage
./ShareX-*-linux-x64.AppImage

Portable

tar -xzf ShareX-*-linux-x64.tar.gz
ShareX-*-linux-x64/app/ShareX              # run it from there
ShareX-*-linux-x64/install.sh              # or add it to your app launcher, for your user only

Preview .deb and .rpm packages are numbered below the release of the same version, so the release replaces them. A copy added with install.sh takes priority in your app launcher; remove it with install.sh --uninstall before switching to a package.

Downloading needs a free GitHub account: GitHub only serves build artifacts to signed-in users. Each build is kept for 90 days. The files arrive inside a .zip that GitHub adds.
