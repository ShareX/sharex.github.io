## What is the remote storage browser?

The ShareX remote storage browser lets you manage configured Amazon S3, FTP, FTPS and SFTP destinations without leaving ShareX. It can browse folders, search the current listing and perform file operations supported by the selected account.

Open it from **Tools** -> **Remote storage browser**.

## Configure a storage account

The browser only shows valid accounts already configured in **Destination settings**. Configure an Amazon S3 destination or add an FTP, FTPS or SFTP account first. See the [Amazon S3 guide](/docs/amazon-s3) for S3-specific setup.

If no supported remote-storage account is configured, ShareX displays an informational message instead of opening an empty browser.

## Browse and manage files

Choose an account from the provider list, then double-click folders to navigate. You can sort the current folder by name, size or modified time and use the search field to filter its visible items.

Depending on the provider and application policy, available actions include:

- Upload files, including drag-and-drop upload
- Download a file
- Create a folder
- Rename a file or folder
- Delete a file or folder
- Preview a remote image
- Copy or open the public URL generated by the configured account

Uploads and other write actions are disabled when uploads have been disabled globally. Operations run against the remote account immediately; rename and delete are not local previews.

## Safety and URLs

Confirm the selected provider and path before uploading or deleting. Remote delete behavior depends on the service, and deleted objects may not be recoverable unless the server has its own versioning or backup policy.

A generated URL is only usable when the account's host, bucket or URL settings make that object reachable. Copying a URL does not automatically change remote permissions or make a private object public.
