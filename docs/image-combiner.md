## What is the image combiner?

The ShareX image combiner joins two or more images into a single image. It can arrange images horizontally or vertically, align images of different sizes, add spacing and wrap long sequences into rows or columns.

Open it from **Tools** -> **Image combiner**.

## Combine images

1. Add at least two image files or drag them into the window.
2. Use **Move up** and **Move down** to set their order.
3. Choose a horizontal or vertical layout.
4. Select the alignment, spacing and optional wrap limit.
5. Review the live preview and select **Combine**.

The finished image is passed to the current ShareX image workflow, where it can be copied, saved, edited or uploaded according to your task settings.

## Layout options

- **Horizontal** places images from left to right. Images can align to the top, center or bottom.
- **Vertical** places images from top to bottom. Images can align to the left, center or right.
- **Space** adds a pixel gap between images.
- **Wrap after** starts a new row or column after the specified number of images. Use `0` for no wrapping.
- **Auto-fill background** fills otherwise transparent gaps when images have different dimensions. Disable it when you want transparent unused areas in a PNG result.

## Common uses

Use the combiner to create before-and-after comparisons, join a series of steps, place desktop and mobile screenshots together, or assemble related captures into one upload.

For a fair visual comparison, resize images to similar dimensions before combining them. Use [Image resizer](/docs/image-resizer) for batch resizing, or [Image comparer](/docs/image-comparer) when you need an exact pixel comparison rather than a side-by-side layout.
