## What is the ShareX image beautifier?

The image beautifier opens an image in the ShareX image editor with the background tools ready to use. It is designed for turning a plain screenshot into a presentation-ready image with spacing, a background, rounded corners or a shadow.

Open **Tools** -> **Image beautifier**, then select the image you want to style.

## Beautify a screenshot

1. Choose an image file.
2. Use the background panel to add the desired presentation styling.
3. Preview the result in the editor.
4. Finish the edit to send the image through the current ShareX workflow, or use the editor controls to copy, save, upload or pin it.

Available background tools include margin, padding, smart padding, rounded corners, shadows, aspect-ratio adjustments and custom backgrounds. These are useful for social posts, release notes, documentation, portfolios and bug reports where a screenshot needs visual separation from the surrounding page.

## Beautifier or image editor?

The beautifier uses the same modern editor described in the [image editor documentation](/docs/image-editor). The difference is where it starts: Image beautifier asks for a file and opens the background panel immediately, while Image editor starts with the general annotation workflow.

You can still use arrows, text, shapes, redaction and other editor tools after opening an image through the beautifier.

## Use beautify as an after-capture task

Enable **Beautify image** under **After capture tasks** to open each new screenshot directly in this presentation workflow. This is convenient when most of your captures use the same styled background or spacing.

Keep important content away from the edges before applying rounded corners, and check the final image at its intended display size so shadows and padding do not overwhelm small screenshots.
