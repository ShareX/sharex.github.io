macOS

macOS 13 or later. The download has a .dmg and a .zip of ShareX.app.

Which one do I need?

Apple silicon (M1 and later) is arm64; Intel Macs are x64. Check under Apple menu > About This Mac > Chip or Processor.

Linux

X11 and Wayland (GNOME, KDE Plasma, Hyprland, sway). Installs for your user, no root needed.

How do I install it? 
unzip ShareX-*-linux-x64.zip
tar -xzf ShareX-*-linux-x64.tar.gz
ShareX-*-linux-x64/install.sh

Then start ShareX from your app launcher, or run sharex.

Downloading needs a free GitHub account: GitHub only serves build artefacts to signed-in users. Each build is kept for 90 days. The files arrive inside a .zip that GitHub adds.
